# Enroll a VeeaHub

Enroll the VeeaHub before you try to enable development mode or manage it with VHT 2.0.

## Physical VeeaHub

If you received a physical VeeaHub, use the Veea support portal enrollment instructions.

```text
https://support.veea.com/
```

A VeeaHub can be enrolled as a standalone unit or as a unit in an existing mesh.

## VM VeeaHub

If you are configuring an Ubuntu VM as a VeeaHub, use the supported VM VeeaHub setup procedure for your development environment. The VM must be reachable from the Ubuntu development host on the same network.

!!! note
    For local VM testing, use bridged networking so the development host and VM VeeaHub can communicate directly on the LAN.

## Next Step

After enrollment, open [Control Center](https://controlcenter.veea.co/) and enable development mode for the mesh.

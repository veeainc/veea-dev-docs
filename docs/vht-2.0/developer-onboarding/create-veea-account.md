# Create a Veea Account

Create a Veea account when you need to sign in to Veea developer services.

## Request Developer Access

Use the Veea developer sign-up flow when you need account access for developer services.

<p>
  <a class="docs-action docs-action--primary docs-register-cta" href="https://developer.veea.com/" target="_blank" rel="noopener noreferrer">Request developer access</a>
</p>

## Create the Account

On the login page, select **Create Account**.

Complete the form, then select **Create a Veea account**.

!!! note
    Developer registration and Veea account creation may be separate depending on your current account state. If registration does not create a usable login, create the Veea account from the login page.

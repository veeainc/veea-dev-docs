# Onboarding Notes

Use these notes when deciding which account and credential steps are required for a VHT 2.0 development environment.

## Login vs Register

The developer portal exposes both **Login** and **Register** paths. If one flow does not give you access to the required developer services, complete the other flow as well.

For now, follow both flows when needed:

1. Register as a developer.
2. Create a Veea account from the login page.

## Registration Feedback

Confirm registration by checking for portal access and any follow-up email validation required by the developer services.

## Developing Without a Partner ID

You do not need a partner ID or feature licenses for simple VeeaHub applications. You can develop applications as long as development mode is enabled.

You need partner credentials or feature licenses when the application uses partner-specific VeeaHub features such as Zigbee, Bluetooth, or networking capabilities.
